# Spotify Clone

A premium, high-fidelity Spotify Web Player clone built with HTML, CSS, and Vanilla JavaScript.

## Features
- **Modern UI**: Dark-themed, glassmorphic layout closely mimicking Spotify.
- **Audio Playback**: Full music player functionality featuring play/pause, volume control (UI), track duration/time status, and next/prev controls.
- **AI Assets**: Album covers generated with AI.
- **Media Sources**: Integrated with Cloudinary-hosted audio/video tracks.

## Technologies Used
- HTML5
- CSS3 (Custom Variables, Flexbox, CSS Grid)
- Vanilla JavaScript
- FontAwesome Icons

## Setup and Running
To run the web player locally, simply download the repository and open `index.html` in any web browser.
